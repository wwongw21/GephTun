## New recovery cases and promotion

Verify provider-read failure, denied/no-effect removals, retained owned rules, failed task removal/absence reads, unreadable worker identity, PID reuse, session mutex ownership and successful retries. Unknown must never become a clean claim.

Confirm the installed script survives. The protected copy may disappear only after policy cleanup and task absence are verified.

Every receipt must identify scenario, exact package/source hashes, observed result and cleanup result. Preserve failed originals and explicit blocks/skips. A later result supersedes an earlier one only with a reason and applicable identity.

The folder cleanup gate is not machine-normalcy evidence. Keep ProductionQualified=false until the applicable live matrix passes on these changed bytes.
