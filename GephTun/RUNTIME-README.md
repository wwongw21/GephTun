# Runtime delivery

This is the complete GephTun 1.5.0 Windows optional kill-switch test candidate. Read README.md and START-HERE.md before running it. Connect supports normal mode with blocking off and protected mode with blocking on. Disconnect and Exit retain any enabled blocking. Normal mode permits direct traffic during interruptions. No automatic crash-recovery service is installed. Current isolated Windows execution receipts are delivered separately. Live WFP and tunnel acceptance remain NOT_RUN.
